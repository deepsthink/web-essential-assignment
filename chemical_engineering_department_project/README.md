## Run with XAMPP
1. Install and open XAMPP.
2. Copy this folder into `C:\xampp\htdocs\`.
3. Start Apache.
4. Open `http://localhost/chemical_engineering_department_project/`.
5. Visit all pages and test the form.

The form is a front-end demonstration; it does not save or email submissions.
