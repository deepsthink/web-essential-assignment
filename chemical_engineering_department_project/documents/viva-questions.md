# Viva Preparation — Questions and Answers

1. **What is HTML5?** Markup used to structure web content.
2. **Why semantic elements?** They make document structure meaningful and improve accessibility and maintainability.
3. **What is CSS?** A language for presentation and layout.
4. **What is localhost?** A hostname that refers to the local computer.
5. **What does Apache do?** Serves project files over HTTP.
6. **What is a relative path?** A path resolved from the current document location, such as `css/style.css`.
7. **Why use alt text?** It conveys image meaning to users who cannot see the image.
8. **Why use a table caption?** It provides a clear title and context for the table.
9. **Why labels on forms?** They identify controls and support assistive technology.
10. **Does this form save data?** No, it is a static demonstration without a backend.
11. **What is Network panel for?** Inspecting resource requests and status codes.
12. **What is Console panel for?** Inspecting browser messages and errors.
13. **What is DNS?** The Domain Name System maps domain names to IP addresses.
14. **State a limitation.** The form does not store or send data and department information is illustrative.
15. **How did you test?** Explain only tests actually performed and show the completed T01–T12 record.
