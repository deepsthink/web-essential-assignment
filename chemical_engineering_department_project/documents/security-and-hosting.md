# Hosting Recommendation and Security Discussion

## Development and hosting
Use XAMPP with Apache. Copy the folder to `C:\\xampp\\htdocs\\`, start Apache, then open `http://localhost/chemical_engineering_department_project/`. A public GitHub repository is suitable for source review. Use only faculty-approved hosting and branding.

## Security precautions
- Never include passwords, API keys or private student information in source files.
- Replace placeholder contact details only with verified, approved information.
- Client-side validation improves usability but is not a security boundary; production applications need server-side validation.
- This static form does not transmit or store data.
- Production hosting should use HTTPS, appropriate access controls, safe data handling and a privacy notice.
- Keep software updated and avoid publishing screenshots containing private tabs or account information.

## Limitations
No backend, database, authentication, email delivery or dynamic updates. Contact and curriculum text is illustrative and must be verified.
