## Internet and Web concepts
- **Internet:** global network of interconnected networks.
- **World Wide Web:** linked resources accessed using web protocols such as HTTP/HTTPS.
- **Browser:** requests resources and interprets HTML/CSS for display.
- **DNS:** maps domain names to IP addresses; localhost refers to the local machine.
- **Web server:** returns requested resources; Apache serves this project locally.
- **HTML5:** structures content; CSS controls presentation.

## Browser request flow
```text
Browser enters localhost URL → Apache receives HTTP request → HTML is returned → Browser requests CSS/SVG → Browser renders page → Developer Tools show DOM, requests and messages
```
