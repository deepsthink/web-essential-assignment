# Requirement Analysis

**Project:** Department of Chemical Engineering Website

## Purpose and users
A multi-page college department site for prospective students, current students, visitors and evaluators. It introduces the discipline, shows illustrative learning areas, provides an enquiry form and contact layout, and documents testing evidence.

## Functional requirements
- Six pages: index, about, courses, register, contact and evidence.
- Shared navigation with current-page indication.
- Captioned course table with row and column headers.
- Labelled form with appropriate input types and browser validation.
- Local SVG media with descriptive alternatives.
- Evidence checklist and T01–T12 test record.

## Non-functional requirements
Semantic HTML5, readable CSS, responsive layout, visible keyboard focus, relative local paths and no external frameworks.

## Acceptance criteria
All six pages load through localhost, links work, CSS and SVG assets load, labels match controls, table headers are meaningful and test results are completed after actual testing.

## Scope
Static front-end only. Form does not save or transmit data. Institution-specific information must be verified by the student.
